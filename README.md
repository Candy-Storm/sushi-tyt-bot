# Telegram-бот «Sushi tyt» (самовиніс)

Бот для суші-бару: реєстрація за номером телефону, щоденна рулетка призів,
промокоди на 24 години та панель касира для перевірки й погашення кодів.

Стек: Python 3.10+, aiogram 3, SQLite (через aiosqlite).

## Структура

| Файл | Призначення |
|---|---|
| `main.py` | запуск бота, фонове закриття прострочених кодів |
| `config.py` | читання `.env`, часовий пояс, TTL промокоду |
| `database.py` | схема SQLite та всі запити |
| `prizes.py` | початкові призи та ймовірності (сума 100%), вибір призу |
| `handlers_prizes.py`, `prize_editor.py` | меню «🎰 Призи» для власника: шанси, назви, додавання й видалення призів |
| `handlers_export.py`, `export.py` | вивантаження клієнтів в Excel для власника |
| `handlers_stats.py` | статистика для власника: клієнти, прокрутки, призи, промокоди за період |
| `backup.py`, `handlers_backup.py` | резервні копії бази: щоденні й за кнопкою, відправка власнику |
| `handlers_user.py` | реєстрація, рулетка, «Мої промокоди» |
| `handlers_admin.py` | панель касира |
| `handlers_broadcast.py` | ручна розсилка власника (вибір групи, перегляд, підтвердження, звіт) |
| `messaging.py` | безпечна відправка повідомлень і автонагадування |
| `keyboards.py`, `utils.py` | кнопки, телефони, час |
| `wheel.py` | малює анімацію колеса фортуни (GIF) |
| `assets/` | шрифт для підписів і готові GIF колеса (`assets/wheel/`) |

## Запуск локально

1. Встановіть Python 3.10 або новіший.
2. Створіть бота в Telegram: напишіть @BotFather → `/newbot` → скопіюйте токен.
3. Дізнайтеся свій Telegram ID у боті @userinfobot (так само для кожного касира).
4. У папці проєкту виконайте:

   **Windows (PowerShell):**
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   ```
   **Linux / macOS:**
   ```
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   ```
5. Відкрийте `.env` і впишіть `TOKEN`, `ADMIN_IDS` (ID касирів через кому) та
   `OWNER_IDS` (ID власника: лише він бачить кнопки «📢 Розсилка», «🎰 Призи» і «💾 Резервна копія»).
6. Запустіть: `python main.py`

Бот працює, доки запущений скрипт. Щоб він працював цілодобово, запустіть його
на сервері/VPS або хостингу для Python (наприклад, через `systemd` чи `screen`).
Файл бази `sushi_bot.db` створюється автоматично — не видаляйте його, там
користувачі й промокоди.

## Як це працює

**Реєстрація.** `/start` → кнопка «Поділитися номером». Приймається тільки
власний контакт у форматі `+380XXXXXXXXX`; номер, надісланий текстом, бот
відхиляє й просить повторити. Один номер можна прив'язати лише до одного
акаунта Telegram (захист від зайвих прокруток з кількох акаунтів).

**Рулетка.** Одна прокрутка на календарний день (за часом `TIMEZONE`, о 00:00
лічильник оновлюється). Якщо вже крутили — бот пише, через скільки можна
наступного разу. Якщо випало «Прокрутити ще раз», одразу доступна ще одна
спроба.

| Приз | Ймовірність | Префікс коду |
|---|---|---|
| Рол у подарунок | 10% | `sushitytroll-N` |
| Знижка 15% | 10% | `sushityt15-N` |
| Знижка 10% | 20% | `sushityt10-N` |
| Напій у подарунок | 20% | `sushitytdrink-N` |
| Спробуй завтра | 20% | — |
| Прокрутити ще раз | 20% | — |

Це початкові призи. Після першого запуску вони потрапляють у базу даних, і далі
їх змінює власник прямо в Telegram (див. «Призи й шанси» нижче); редагувати
`prizes.py` для цього не потрібно.

**Анімація колеса.** Під час прокрутки бот надсилає GIF: колесо крутиться,
гальмує і зупиняється стрілкою саме на виграному секторі (розмір секторів
відповідає ймовірностям), а потім підпис під анімацією змінюється на результат.
Результат визначається ще до анімації, тому колесо завжди «чесне».
Для кожного призу є свій готовий файл у `assets/wheel/`. Якщо власник змінив призи,
колесо перемальовується само (це займає
близько пів хвилини, потрібен Pillow із `requirements.txt`). Підписи секторів
і кольори налаштовуються в `wheel.py` (словник `STYLE`). Якщо анімацію
показати не вдалося, бот використає простий текстовий варіант.
Шрифт для підписів — DejaVu Sans Bold (вільна ліцензія, лежить у `assets/`).

**Призи й шанси (лише власник, `OWNER_IDS`).** У панелі касира є кнопка
«🎰 Призи» (або команда `/prizes`). Власник бачить список призів із шансами й може:
- змінити шанс призу (число від 0 до 100; з 0% приз не випадає, але лишається в списку);
- змінити назву призу, яку бачить клієнт;
- змінити короткий підпис сектора на колесі (до 8 символів, без емодзі);
- додати новий приз (до 10 призів): назва, чи видавати промокод (тоді власник
  вигадує префікс, наприклад `sushitytset`, і коди матимуть вигляд `sushitytset-1`,
  `sushitytset-2` ...), початковий шанс;
- видалити приз; кнопка «🔄 Початкові призи» повертає стандартний набір.

Нічого не застосовується, доки власник не натисне «✅ Зберегти», а зберегти можна лише
коли сума шансів рівно 100% (бот показує, скільки бракує чи скільки зайвого, і на
кожному кроці пропонує кнопку «Поставити N%» для добору до 100). Зберігаються й діють
призи одразу, без перезапуску бота. Колесо перемальовується у фоні (приблизно хвилину),
доки воно не готове, клієнти бачать звичайну текстову рулетку. Уже виданих промокодів
зміни не стосуються: коди видаленого призу діють до кінця терміну й показуються з
його назвою.

**Промокоди.** Нумерація окрема для кожного префікса: `sushityt10-1`,
`sushityt10-2`, … Код діє 24 години з моменту виграшу. Статуси: `active`,
`used`, `expired`. Прострочені коди переводяться в `expired` кожні 5 хвилин і
перед будь-яким переглядом.

**Касир.** Користувачі зі списку `ADMIN_IDS` бачать у меню кнопку
«🛠 Панель касира» (або команда `/admin`). Далі «🔍 Перевірити код клієнта» →
ввести номер `+380XXXXXXXXX` (також підходить `0XXXXXXXXX` або сам промокод).
Бот показує коди клієнта по групах (активні / використані / прострочені) з
часом отримання й закінчення. Під кожним активним кодом є кнопка
«Позначити як використаний»; після натискання код погашено остаточно.

**Ручна розсилка (лише власник, `OWNER_IDS`).** У панелі касира з'являється
кнопка «📢 Розсилка» (або команда `/broadcast`). Порядок: вибираєте групу →
надсилаєте текст або фото з підписом (форматування Telegram зберігається) →
бот показує точно те, що побачать клієнти, і кількість отримувачів → «✅ Надіслати».
Після завершення приходить звіт: скільки доставлено, скільки заблокували бота,
скільки помилок. Одночасно може йти лише одна розсилка. Групи:
- усім клієнтам;
- з активним промокодом;
- не крутили кілька днів (бот спитає, скільки саме: 2, 3, 5, 7 або 14);
- нові (зареєструвалися за останні 7 днів);
- ті, хто жодного разу не крутив.

**Автонагадування (бот пише сам).**
- «Ваш промокод скоро згорить»: за 6 годин до кінця дії, по одному разу на код;
  кілька кодів одного клієнта йдуть одним повідомленням.
- «Рулетка чекає»: клієнтам, які 3 дні не крутили; не частіше ніж раз на 7 днів,
  і не більше двох поспіль без жодної прокрутки у відповідь.
- Тихі години з 22:00 до 09:00: у цей час нагадування не надсилаються (якщо 6 годин
  до кінця коду випадають на ніч, нагадування приходить увечері о 21:00).
- Одному клієнту не більше одного автонагадування на добу.
- Нагадування працюють, лише поки бот запущений, тож для них він має працювати цілодобово.

**Сповіщення клієнтів.** Під кожною розсилкою й нагадуванням є кнопка
«🔕 Вимкнути сповіщення»; також є кнопка «🔔 Сповіщення» в головному меню, де їх
можна вимкнути й увімкнути. Хто вимкнув сповіщення чи заблокував бота, не
отримує ні нагадувань, ні ручних розсилок. Якщо клієнт розблокує бота, він
знову з'являється в списках. Часи й ліміти змінюються в `config.py`.

**Статистика (лише власник, `OWNER_IDS`).** Кнопка «📊 Статистика» в панелі касира
(або `/stats`) показує зведення за період; кнопки під повідомленням перемикають його:
«Сьогодні», «7 днів» (за замовчуванням), «30 днів», «Весь час». Дні рахуються за місцевим часом.
- **Клієнти:** скільки зареєстровано всього, скільки нових за період, скільки вимкнули
  сповіщення чи заблокували бота;
- **Рулетка:** кількість прокруток і скільки клієнтів крутили, скільки з них поверталися
  (крутили в різні дні), що випало й як часто;
- **Промокоди:** скільки видано, використано, ще активних і прострочених, які призи
  забирають найчастіше, скільки погашено касирами за період.

Прокрутки, стерті командою `/reset`, у статистику не входять. Призи, видалені з рулетки,
у старій статистиці лишаються під своїми назвами.

**Клієнти в Excel (лише власник, `OWNER_IDS`).** Кнопка «📥 Клієнти (Excel)» в панелі касира
(або `/clients`) надсилає таблицю `.xlsx` зі всіма клієнтами (нові зверху): телефон, Telegram ID,
дата реєстрації, кількість прокруток і остання прокрутка, скільки промокодів видано, використано
й активних зараз, чи ввімкнені сповіщення, чи заблокував клієнт бота. У таблиці є фільтри.
Там номери телефонів, тому не пересилайте файл стороннім.

**Резервні копії (лише власник, `OWNER_IDS`).** Уся база (клієнти, промокоди, призи)
лежить в одному файлі `sushi_bot.db`, тож бот береже її сам:
- щодня о 04:00 за місцевим часом бот робить копію, пакує її в zip, зберігає в папці
  `backups/` (останні 14 штук, старіші видаляються) і **надсилає файл власникам у Telegram**;
  якщо бот був вимкнений о 04:00, копія зробиться одразу після запуску;
- у будь-який момент можна натиснути «💾 Резервна копія» в панелі касира (або `/backup`):
  файл прийде лише вам;
- копія цілісна, навіть коли в цей момент хтось крутить рулетку, і перевіряється перед
  пакуванням; якщо щось пішло не так, власники отримують повідомлення (раз на добу).

Папку для копій можна змінити в `.env` (`BACKUP_DIR`). Файли в Telegram важливіші за
папку на сервері: деякі хостинги стирають файли при перезапуску, а повідомлення з
копією лишається в чаті. У копії є номери телефонів клієнтів, тому не пересилайте її стороннім.

**Як відновити базу з копії:**
1. Зупиніть бота (Ctrl+C у терміналі).
2. Розпакуйте zip із копією: усередині буде файл `sushi_bot.db`.
3. Покладіть його в папку бота замість поточного `sushi_bot.db` (зробіть копію старого,
   про всяк випадок). Якщо поряд є файли `sushi_bot.db-wal` і `sushi_bot.db-shm`, видаліть їх.
4. Запустіть бота: `python main.py`. Усі клієнти, промокоди й призи будуть на місці.

**Скидання прокруток (для тестування).** Лише для `ADMIN_IDS`: команда `/reset`
скидає ваші прокрутки за сьогодні, щоб можна було крутити рулетку знову;
`/reset +380XXXXXXXXX` робить те саме для клієнта з цим номером. Уже виграні
промокоди не видаляються. Для цього ви маєте бути зареєстровані як клієнт
(`/start` → «Поділитися номером»).
